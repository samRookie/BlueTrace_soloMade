# Phase Boundaries & Scope Protection — Phase 2

## Phase 2 Objective

Phase 2 establishes the **PostgreSQL persistence layer, relational schema, indexes, constraints, database base utilities, and deterministic demonstration data graph** for SIH26019.

## Explicit Out-of-Scope Capabilities

The following capabilities belong to future implementation phases and remain **strictly excluded** from Phase 2:

- **Authentication & Authorization Enforcement**: No login endpoints, password hashing, JWT generation, session stores, or permission enforcement middleware.
- **Business Repositories & Domain Services**: No full CRUD services or domain workflows for policies, disputes, projects, or verification.
- **Business Dashboards & UI Expansion**: No application dashboards, map viewers, evidence explorers, or workflow screens.
- **GIS & Spatial Intelligence**: No geometry engines, spatial query processors, or raster/vector rendering tools (GIS layers remain metadata-only).
- **Blue Carbon & Environmental Analytics**: No scientific carbon equations, satellite processing algorithms, or ecological calculation engines.
- **AI & LLM Services**: No LLM API calls, embeddings, or recommendation algorithms.
- **Government System Integrations**: No external land registry API clients, municipal connectors, or fake government endpoints.
- **Real-Person Sensitive Data**: Zero real individuals, personal identification numbers, contact information, or confidential land records.
